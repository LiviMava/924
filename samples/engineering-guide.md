# 星河项目工程协作指南（虚构演示资料）

本文档仅用于 RAG 演示与测试。

## 代码评审

所有生产代码变更都应提交 Pull Request，并由至少一名同事完成评审。合并前必须通过单元测试和持续集成检查。

## 发布流程

发布顺序为：测试环境验收、负责人批准、生产部署、健康检查。部署失败时使用上一份已验证的构建产物回滚，并记录故障原因。

## 接口集成

公司内部系统接入知识库时，使用服务端颁发的 Bearer Token。不得把模型供应商的 API Key 放入浏览器代码。调用方应记录响应头中的 X-Request-Id 以便排查问题。

## 本文未覆盖事项

本指南没有规定生产数据库的备份保留天数，也没有规定 VPN 账号的申请流程。对这些问题应查找其他正式文档。
